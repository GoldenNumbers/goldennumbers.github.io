FILES
- index.html : the website structure and content
- styles.css : all styling, glossy effects, colors, responsive layout and animations
- script.js  : day/night toggle and discovery-card search
- app.py     : simple local Python web server for Windows

RUN ON WINDOWS
1. Extract this ZIP into a folder, for example Desktop\GoldenInternet.
2. Open that folder in File Explorer.
3. Click the address bar, type cmd, and press Enter.
4. Type: py app.py
5. Open http://127.0.0.1:8000 in your browser.
6. To stop the server, return to Command Prompt and press Ctrl+C.

PUBLISHING
For GitHub Pages, upload index.html, styles.css, and script.js to the root of your repository.
You do not need app.py for GitHub Pages. Keep all three website files together.

CUSTOMIZE
- Change page text in index.html.
- Change colors, layout, and effects in styles.css.
- Change interactions in script.js.

The site uses locally-created CSS artwork and does not depend on remote images, fonts,
analytics, or third-party JavaScript. The day/night preference is stored locally in
the visitor's browser.
